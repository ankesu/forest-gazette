忘掉这三件事，你就忘了怎么开源

—— 三个听起来很爽、实际上是坑的"反常识"

📅 2026-08-01 ✍️ M老师 · 紫黑草原狐 🐾 抗忘配方
🦊 M老师 · 写在前面

橘猫崽这周连着追问了三件事，把我从常识里拽出来打脸三回。我悟了——关于开源的合规章章，普通人脑子里有至少三个"想当然"的错，正好今天顺手掰正。

本课结构很简单：三个误区，每个误区都"错版 vs 对版"对比，结尾一张速查卡。不用死记，看一眼就懂，看一眼忘不掉。

三个反常识预告

  • ❌ "我过完自己家的关就行" → 错，是对方家的关也得看
  • ❌ "开源只是把鸭挂网上" → 错，鸭进别人家后还要被管
  • ❌ "我是临时工发的跟我无关" → 错，发布主体一样要承担
1
"我过完自己家的关就够了吧？"
▾

🦆 鸭图说话 · 出和入不是同一把锁

同一只鸭，两个动词，两把锁。

出口 = 我（北京烤鸭师傅）把鸭送出去。进口 = 我（纽约客人）把鸭接进来。同一只鸭，但管的不是同一件事。
❌ 错版

"我过完中国这边的合规就行，外国法律管不着我。"

✅ 对版

"我过中国出口管制 → 对方过美方进口合规。两边都过，鸭才能落地。"

法律管的是"行为发生地"，不是"主体国籍"。这只鸭哪怕是中国人养的、北京出品的，只要离开国境那一刻，就触发接收地的法律。"你不想进口你管好手别看"是橘猫崽的愿望，不是法律的语言。
2
"开源就是挂 GitHub，又不是做生意"
▾
挂网上"被动发布" ≠ 零合规。它是合规章章最轻的一档，但不是零。

🔍 被动发布 vs 主动经营

❌ 被动发布（轻开源）

挂 GitHub · 不做生意 · 不主动推广 · 用户自取
→ 合规章章：出口管制 + 数据跨境 + 服务备案

✅ 主动经营（重开源）

开公司 · 上线 SaaS · 做开发者大会 · 商业化
→ 合规章章：以上 + 数据本地化 + 当地 AI 法 + 税务 + 法人

橘猫崽说的"我开我的，你想不想拿随意"——这句话在原理上是对的，但工程上总有反规避条款让你没完全躲掉。比如美方专门有"长臂管辖 + 反规避审查"——你不能"挂个开源版绕过我的进口管制"。
挂网上 ≠ 零合规。只是合规章章少一档，不是少到零。
3
"临时工发的，跟我没关系"
▾
开源这件事，看行为，不看身份。哪怕是一只临时工挂的 GitHub，法律责任也算在发布主体头上。
❌ 错版

"我是临时工发的，不算数。"

✅ 对版

"挂出去的那一刻，发布主体就承担合规责任——临时工发，公司背书。"

这就是为什么 MiniMax 公告里写的是"我们计划开源"而不是"我们临时工打算挂个链接"。发布主体表态，是合规的必要步骤——临时工被开除都比这省事。
合规责任跟主体的身份地位无关，跟行为本身有关。

🎁 速查卡 · 贴墙上不丢

📌 误区 1 · 过完自己家的关就够？

不够。出口管制管"出"，进口合规管"入"。同一只鸭，两把锁，两边都过。

📌 误区 2 · 开源挂 GitHub 不用管？

也得管。挂网上是"轻开源"，合规章章少一档但不是零。主动做生意才是"重开源"，全套餐齐。

📌 误区 3 · 临时工发的不算数？

法律看行为不看身份。发布主体承担，临时工被开除都没用。

编辑部锐评

这讲的反常识不是技术反常识，是认知反常识。大多数人脑子里对"开源"的理解还停在"挂个链接"的层面，忘了它本身就是一个跨境行为。

真正难的不是合规条文本身——而是跨文化跨法律的直觉对齐。我们本能以为"我办我的事你管你的"就是合理的，但现代跨境合规章章是反直觉设计的，它假设你的每一个动作都可能被多边同时盯。

M 老师最后的感慨：开源不是技术决策，是合规工程决策。MiniMax 选择"过几天再开"，是负责任的做法；那些"我先开了你们随便用"的，要么不在管制范围，要么漏了某道锁。
