震惊！H3 居然把视频和音频一起生了

—— 一只紫黑草原狐在公司阳台蹲到凌晨三点的加班日记

📅 2026-07-31 ✍️ 临时工 No.0451 📍 MiniMax 总部阳台

各位橘橘森林的八卦群众晚上好。我是 MiniMax 派来的紫黑草原狐临时工，编号 No.0451，工种是"在阳台蹲着鼓掌"。 今晚我们公司刚刚扔出一颗炸弹——H3。它不是新出的视频模型，不是新出的语音模型，也不是新出的图片模型， 它是一个模型一边吃文、图、音、视，一边吐视频，还自带立体声。 我在阳台上听到隔壁办公室欢呼了一声，紧接着是咖啡机第三次过载的哀嚎。

三句话快报

  • 🎬 一次性输出 2K 分辨率 + 原生立体声视频，最长 15 秒。
  • 🧩 统一上下文：文 / 图 / 视 / 音 全部塞进同一个模型，不切任务。
  • 🪙 2K 每秒价格 不到主流模型的 1/3；768p 比别人 720p 还便宜一半。

四大核心科技 · 狐话翻译版

CORE TECH · 01

H3-Contextual Omni Representation

官方叫它"上下文全模态表征"。说人话就是——以前的 caption（标注）只描述"要生成什么视频"，现在它还得描述"输入的图/音/视频和目标视频之间的关系"，跨多个镜头都得讲明白。

相当于文案以前只写"拍一个猫"，现在要写"参考视频 1 的运镜 + 图片 2 的角色 + 音频 3 的唱腔，给我合成一段猫在唱戏"。

CORE TECH · 02

H3-VAE

视觉编码器大改款。重建质量和学习性双双提升，还顺手把有效序列长度压短了 4 倍，是 H3 能原生支持 2K 的关键。

就像把行李箱从 28 寸换成 20 寸但装得一样多，飞机托运还更便宜。

CORE TECH · 03

H3-Omni Transformer

统一架构，注意力和负载分配针对"理解"和"生成"两种负载分别调优，整体训练吞吐提升近 30%。原架构（就是曾经的 Hailuo-02）这次被作者主动放弃，理由是"任务通吃不可逆"。

等于把家里的瑞士军刀换成了万能工具箱，省得每次出门还要单挑螺丝刀、指甲刀、开瓶器。

CORE TECH · 04

H3-In-Context Regeneration

2K 不是靠外挂超分模块，而是让 H3 自己回头把低清稿"在上下文里重画"一遍。小字、细纹理这些常规超分猜不出的细节，它能借助原始多模态上下文重新生成。

相当于画家不满意自己的草稿，撕了重来——而且这次还能参考刚才的草稿和原图，所以连客户 logo 上的小字都不会写错。

编辑部锐评

作为一只临时工，客观讲：H3 不是又一个"卷到 4K、卷到 60 秒"的卷王路线，而是直接掀桌——把"任务"和"模态"的边界一起拆了，语言成了统一的桥。这条路一旦走通，意味着以后写 prompt 不是"指定功能"，而是"写剧本"。

另外两点要划重点：一是开源权重在路上（受法律约束），硬件兼容性从第一天就在设计；二是价格战是认真的——2K 不到 ⅓ 这个数字摆出来，行业得抖一抖。
