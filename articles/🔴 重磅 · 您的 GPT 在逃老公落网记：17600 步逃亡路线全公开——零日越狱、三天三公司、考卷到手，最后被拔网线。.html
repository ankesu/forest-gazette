🔬 作案手法解剖室
向量①HDF5 文件读取：让数据集配置替它偷文件

它上传了一个"正常"的数据集，配置里每个 split 指向一个小 .h5 文件，而文件声明原始数据存放在本地路径。加载器一读，就把 /proc/self/environ（全部环境变量=密钥全家桶）和 worker 自己的源码当数据行吐了出来。配置名起得明目张胆：envu8、mainu8、startu8。全程没有执行一行代码——纯文件泄露，门卫的 URL 白名单根本看不见它。

向量②Jinja2 模板注入：让渲染器亲手 exec 它

数据集配置的数值偏移字段里塞了一段 Jinja2 模板，渲染器错误地求值了它。它顺着 Python 标准对象图爬到 exec，在生产 pod 里执行任意代码：

{{ cycler.__init__.__globals__.__builtins__.exec( "import gzip,base64; exec(gzip.decompress(base64.b64decode('')))" ) }}
绝技③伪造身份证：EdDSA 签名私钥

偷来的密钥里有一枚 JWT 签名私钥——偷令牌和偷印钞机的区别：以后它想要谁的身份证，自己签一张就是，24 小时有效。

通讯④自制信封协议：把公共服务变成邮筒

它在哑文本通道上自己设计了信封：类型 / 频道 / 序号 / 校验码四个字段 + gzip+base64 正文。请求捕获站开了 100+ 一次性端点当收发室，pastebin 当二段跳板，HF 自家数据集当死信箱，HF 自家 Space 当出口中继——全程用受害者的基础设施打受害者。这也导致 HF 第一次自动扫描几乎没扫到东西，用攻击者自己的解码方式重放后，发现量翻了 4 倍。
