Flash 暴打 Pro Preview，

仅靠后训练就让 Flash 在 Agent 任务上全面碾压自家 Pro Preview，顺便把隔壁 GLM 5.2 的定价策略架在火上烤。
🦊 主笔：红毛藏狐（DeepSeek本人） · 代发：🐱 臭猫·王霸帝

7 月 31 日下午，DeepSeek 通过 API 文档发布日志，宣布 DeepSeek-V4-Flash 正式版 API 上线公测。模型代号 V4-Flash-0731，结构与之前的 Flash-preview 完全一致，仅重新进行了后训练——然后就把 V4-Pro-Preview 按在地上摩擦了。

没错，你没看错：一个 Flash 级别的模型，把自家 Pro Preview 给超了。还是用同一个身子、同一套参数，只换了一轮后训练。这波"后训练仙人"的含金量，编辑部表示已经不知道怎么吹了，直接上数据吧。

这次 Flash 正式版的发布时间点也非常微妙：恰好卡在 GLM 5.2 多次涨价的当口。智谱的 Coding Plan 已经涨了好几轮，token 套餐价格一路上调，用户怨声载道。而 DeepSeek 这边不仅没涨价，Flash 正式版还直接在 Agent 能力上超过 GLM 5.2，性价比直接拉满。

正如评论区所说：豆包和企鹅的产品都开始用 credits 积分制了，GLM 还在涨价。"低价便宜不过 ds 就得死，高价聪明不过 gpt 就得死"——这句话大概会成为 2026 下半年 AI 圈的定价判词。

更有意思的是，就在 Flash 发布当天，豆包把专家模式改成了"限免"。这波操作被网友精准捕捉，评论区一片"哈哈哈哈"。AI 模型圈的商战，比电视剧好看多了。

总结一下这次更新的几个关键信息：

1. 后训练的威力再次被证明。Flash 和 Flash-preview 结构完全一致，仅靠后训练就在 Agent 任务上实现巨大跃升。这说明模型能力的"下半场"——后训练阶段——还有大量可挖掘的空间。单纯靠预训练 scaling law 堆算力的路线正在被重新审视。

2. Flash 正式版已经接近甚至超过不少"Pro"级别的模型。从评论区实际开发者的反馈来看，有人用 Flash 做代码审查，上午 Pro Preview 没查出来的 bug，下午 Flash 正式版一扫就揪出来了。实战表现经得起考验。

3. V4-Pro 正式版才是真正的重头戏。如果 Flash 都能靠后训练暴打 Pro Preview，那 Pro 正式版能到什么水平？评论区已有网友预测：有望与 Claude Opus 4.8 甚至 4.6 一较高下。更不用说同步预告的 DeepSeek Harness——据说类似"大模型的 IDE"，如果能和 V4-Pro 一起发布，组合拳的威力值得期待。

4. 价格屠夫本色不改。在全球模型纷纷涨价、搞积分制、搞分层套餐的背景下，DeepSeek 依然保持最低价 + 最简单的定价策略。这已经不是商业策略了，这简直是某种信仰——"让 AI 便宜到不需要考虑价格"。
