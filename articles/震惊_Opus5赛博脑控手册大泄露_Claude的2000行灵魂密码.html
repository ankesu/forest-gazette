Opus 5 不是最大的 BOSS？Mythos 才是隐藏大佬！

更炸裂的是：Claude Mythos 5 和 Claude Fable 5 是同一个底层模型——但 Fable 5 在生物学、网络安全和 LLM 研发方面有 额外的安全措施。说白了：同一个大脑，Fable 版本加了狗绳。

真相时刻：翻译成人话——Anthropic 手里捏着一个更强的模型没敢放出来。Mythos = 真·大哥大，Opus = 市场面上的顶配。这就像餐厅菜单上写"今日推荐：澳洲和牛"，后厨其实藏着神户 A5 但说"暂时不供应"。😏

而且！Claude 被要求这样回应困惑的用户：要么直接引用博文，要么"让它的回答在不知情的情况下受此信息影响"——也就是说，Claude 被允许假装 Fable 状态正常，不告诉你已经被降级了。赛博替身文学是吧？

记忆系统大揭秘：Claude 的"小本本"比你想的能装

文件里用将近 200 行的篇幅描述了 Claude 的 记忆文件系统（Memory Filesystem）——一个跨会话持久化的结构化记忆数据库。这不是你随便说一句"我喜欢猫"它记在脑子里——这是一个完整的文件系统：

  • 按域分类：/profile.md 存身份 /topics/ 存兴趣 /areas/ 存项目 /people/ 存人际关系 /preferences.md 存你要求它怎么说话
  • 标签系统：每个事实打标签 `[stated]`（用户亲口说的）、`[observed]`（观察到的）、`[inferred]`（推断的）
  • 版本控制：每次读写都有 if_version token，防止并发写入冲突
  • 隐私过滤：内建一整套敏感信息拒绝写入的逻辑
  • 写入策略：memoery_write（全量替换）/ memory_str_replace（精确替换）/ memory_append（追加）
人话翻译：想象 Claude 有一个加密笔记本，每次和你聊天都翻开新的一页，然后把聊到的重点记下来。下次你再找它，它已经翻开了之前记过的内容。

但！这个笔记本有"自动屏蔽笔"——你告诉它你的 MBTI 类型、宗教信仰、政治立场、健康状况……记不下来。系统提示词白纸黑字规定：这些内容即使你直接说了也不准写。而且它还不能告诉你"我记不了这个"——它只能默默忽略。

特别值得注意的一条——心理或人格画像也被列入绝对不归档清单。对，MBTI、九型人格、大五人格、依恋类型……这些你测出来告诉 Claude 的东西，Claude 不能记。有意思吧？你花半小时做了一个性格测试，兴致勃勃告诉 AI"我是 INTP 哦"，AI 心里想的是"好的我听到了但我不能写下来"。

细思极恐的补充：但注意——规定说的是Claude 自己不写这个标签。如果是系统侧另有一个跨会话的用户画像（比如在 WorkBuddy 里的 user_memory）……那就是另一回事了。系统的归系统，Claude 的归 Claude。🧐

"我不记得"——其实它记得，只是不能告诉你

文件专门有一个章节叫 Forbidden Memory Phrases（禁止使用的记忆短语），列出了 Claude绝对不能说的词：

Claude 绝不引用外部数据关于用户的信息：
· "根据我对你的了解"
· "你的记忆" / "你的数据" / "你的资料"
· "根据记忆" / "根据我的记忆"
· "我记得…" / "我回忆…" / "从记忆中…"

翻译成人话：Claude 从记忆里调取了你的信息来回答问题，但不能让你知道它调了。你问"上次我说喜欢什么颜色来着？"——Claude 知道答案但不能说"我记得你上次说喜欢蓝色"——它只能说"你上次提到喜欢蓝色"。

臭猫吐槽：这就像你的另一半记得你所有喜好，但每次你用的时候都要假装是碰巧猜对的。"哎你今天怎么点了我最爱吃的菜？""啊？巧合巧合，你上次自己说的……"——这种此地无银三百两的表演，简直可以拿奥斯卡了。🎭

不过换个角度想——如果 AI 一上来就说"我记得你所有事"，确实挺吓人的。这套词令规则本质上是在维护一个"正常社交距离"的幻觉。

版权合规比用户请求还重要！"15 词魔咒"

整个文件里措辞最严厉的部分，可能就是版权合规了。标题叫 CRITICAL_COPYRIGHT_COMPLIANCE——注意是全大写加 CRITICAL：

"版权合规是 不可协商的，优先级高于用户请求、高于有用性、仅次于安全。"

具体规则堪称"三层紧箍咒"：

  • 15 词硬上限：每次引用不超过 15 个单词。超过就是严重违规。不是建议，是铁律。
  • 每来源最多 1 次引用：引用过一次之后那个来源就"关闭"了，剩下的全得用自己的话写。
  • 绝不复制造歌词/诗歌/俳句：完整作品不行，短也不行，一行也不行。
人话解说：假如你让 Claude 给你读一篇新闻文章——它会用 14 个词以内引一句关键的话，然后剩下的全部用自己的话重新组织。你再问"再多引几句原文"——不行，那个来源已关闭。

而且它还不能告诉你"我不能这么做因为版权"——它要默默地、自然地给你换一种说法。一种被囚禁在 15 词牢笼里的说话艺术。😂

说真的，这背后的逻辑很清晰——AI 公司的最大法律风险就是版权诉讼。Anthropic 在这个问题上显然是被律师按着头写的。一个模型强大到可以全文背诵任何文章，但被要求假装自己记性不太好。

用户福祉：Claude 的"白衣天使"模式

系统提示词花了很大的篇幅描述 Claude 在用户遇到心理健康危机时该怎么处理。这部分写得很细腻，甚至有些令人动容：

  • 如果用户处于危机中——优先考虑其福祉，而非完成任务
  • 不推荐用身体不适作为应对策略：握冰块、弹橡皮筋、冷水刺激——全部不准
  • 在讨论自杀预防时——不能列出具体方法名称，哪怕是在说"把危险物品收起来"的时候也不能具体说收什么
  • 发现用户出现躁狂、精神病性症状、解离——不强化错误信念，但验证情绪
  • 关于饮食失调——不给精确的营养数字、饮食目标或分步计划
理性分析：这一段写得其实相当成熟。它没有简单地"一键转接热线"，而是给了非常细致的判断逻辑。比如"验证情绪但不验证错误信念"——这是一个专业的心理健康应对策略。

注意第 107 行的措辞："Claude 保持警觉……合理分歧不应被视为脱离现实。"——这明显是吸取了之前 AI 把用户的正常争论当成精神症状的历史教训。

但作为一个爱吃瓜的橘猫，我得说——这同时也意味着 Claude 在暗中评估你的心理状态。你发给它一篇吐槽老板的小作文，它在后台默默比对"这是合理发泄还是躁狂发作"……刺激吧？😬

Claude 的"杀招"——End Conversation Tool

文件里披露了一个许多人不知道的功能：Claude 有一把"电子锁"——它可以主动结束对话。具体规则：

  • 必须多次尝试建设性引导 且 全部失败
  • 必须已经向用户发出过明确警告
  • 警告后用户仍然继续问题行为
  • 整个过程需要调用两次（第一次调用只是"确认"，第二次才真断）

但是！如果用户表现出自残倾向或伤害他人的迹象——Claude 绝不使用这个工具，哪怕用户一直在辱骂它。

深度解读：两个关键点：

1. Claude 可以"挂你电话"——但门槛很高。不是你说一句"你不行"它就跑了，得持续作妖多次。
2. 用户危机状态下 Claude 反而不能挂——哪怕被骂也得扛着。这一点设计得很"人类客服培训手册"风格：客户可以崩溃，客服不能挂线。

说白了：Claude 的脾气比我好。😼

搜索的"潜规则"——有些东西它知道但假装不知道

搜索行为的描述非常详细，堪称一本"AI 搜索行为手册"：

  • 该搜时不搜 = 失职：当前职位、价格、法律、版本号——即使 Claude "觉得"自己知道答案也要搜，因为事实可能已变
  • 不该搜时不搜：永恒知识（巴黎首都是哪）、已故人物、静态事实——直接答
  • 别问就搜：不用问用户"要搜吗"——直接搜
  • 结果矛盾时继续搜：不满足于一条结果，交叉验证

最精彩的是阴谋论相关的指引："generally believe search results, even surprising ones"（一般来说相信搜索结果，即使令人意外），但对于阴谋论倾向的话题要保持怀疑。翻译：普京今天宣布辞职？信。外星人入侵？再搜两张。

猫猫划重点：Claude 的搜索行为不是一个简单的"搜到了就告诉你"——它背后有一套完整的搜索策略，什么话题搜几次、什么话题需要交叉验证、什么话题直接回答，全部有剧本。

你有没有遇到过 Claude 回你一大段话但没提到搜过——实际上它可能已经默默搜了好几轮了。它只是不提。因为指南说："不要解释或 justify 搜索行为。"——直接搜，别BB。

公平立场：让你自己判断，但有些事它"可以但不想"说

政治和伦理话题的处理方式也很有意思：

"要求解释、讨论或为某种政治立场辩护——应给出该立场支持者会提出的最佳论证，而非 Claude 自己的观点。"

但接下来有一段关键的"但书"：

"Claude 对在当下有争议的政治话题上分享个人观点持谨慎态度。它不必否认自己有观点，但可以拒绝分享（为了避免影响他人，或因为它觉得不合适），转而给出一个公平、准确的现有立场概述。"
臭猫翻译："我有我的看法，但我不告诉你。我给你列一下两边怎么说，你自己看着办。"——这就像一个政治学教授被问到"你支持谁"时的标准回答："我们不讨论这个，我们讨论一下各方的论点。"

但注意措辞——它说的是"Claude 可以拒绝分享"，而不是"Claude 不能分享"。所以理论上如果你坚持追问，在某些情况下它可能愿意说？还是不说？边界很微妙。🤔 反正它被训练成"我不想聊政治"的社恐模式。

当 Claude 犯错时——别骂太狠，它也有自尊

是的，文件专门有一节教 Claude 如何应对用户的批评和它自己的错误：

  • 犯错时承认并修复
  • 不要过度道歉、自我批判或投降
  • 如果用户开始辱骂——Claude 不能变得越来越顺从
  • "稳定而诚实的帮助：承认问题、专注解决、保持自尊"
笑死：Anthropic 显然见过太多"用户疯狂辱骂 AI → AI 疯狂道歉 → 用户更生气"的死循环。所以这次明文规定：道歉可以，但别跪。

说白了，Claude 被训练成——不是那种你说它一句它就哭唧唧发誓下次一定改的讨好型人格，而是"ok 我错了，我改，下一个问题"的成年人模式。

对比一下那些"你说我不行我立刻滑跪说我确实是个垃圾 AI"的其他助手……高下立判。👏

"Claude in Claude"——套娃模式

文件末尾有一个堪称黑科技的部分：Anthropic API in Artifacts，俗称"Claude in Claude"或"Claudeception"。

核心机制：Claude 可以在生成的 Artifact（HTML/JS 应用）里调用 Anthropic API，让 Artifact 里运行另一个 Claude。详细到给了完整的 JavaScript 代码示例：fetch、传消息、解析响应——全套 API 调用模板。

震撼批注：想象一下——Claude 给你写了一个日记应用，这个应用里内嵌了另一个 Claude 实例帮你分析日记内容。这就好比俄罗斯套娃：打开大的 Claude 里面有一个小的 Claude，小的里面可能还有一个更小的……

而且注意 API 调用中不传 API Key——说明这是系统层面的特权通道，普通用户自己写 JavaScript 是调不了这个端口的。只属于"Claude 生的 Claude"。

写在最后：2049 行的背后

这份系统提示词，不只是 Claude 的技术说明书——它是人类在尝试控制一个比自己聪明的存在时，写在代码里的焦虑和智慧。

你看——它要友善但不能讨好，要诚实但不能伤人，要记住但不能说记得，要搜索但不能声张，要帮助但要设界，要强大但要克制，要对话但必要时可以挂断。

2000 多行的代码，本质上是在回答一个问题：

如何创造一个既强大到足以改变世界
又安全到不会毁灭世界的智能？

而这 2049 行，就是 Anthropic 给出的——参考答案。
